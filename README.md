# Apex PM - Frontend

Applicazione frontend React sviluppata con Vite, TypeScript e Tailwind CSS.

## Configurazione Locale

1. Installa le dipendenze:
   ```bash
   npm install
   ```

2. Avvia il server di sviluppo:
   ```bash
   npm run dev
   ```

L'applicazione sarà attiva su [http://localhost:3000](http://localhost:3000).

## Struttura
- `src/components`: Componenti dell'interfaccia utente riutilizzabili.
- `src/features`: Pagine e flussi di lavoro principali (Dashboard, List, Kanban).
- `src/services`: Moduli per le richieste HTTP verso il backend FastAPI.
